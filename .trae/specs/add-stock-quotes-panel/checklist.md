# Checklist

## 页面与导航
- [x] 应用内含「提醒 / 行情」主导航，两者可切换且各自页面状态被保留
- [x] 重启后默认进入上次停留页面；首次使用默认进入「提醒」页
- [x] 行情页刷新、失败或休市时不产生任何提醒类系统通知，提醒功能行为与改动前一致

## 指数卡片
- [x] 行情页顶部固定展示上证指数、深证成指、创业板指三张卡片（顺序固定）
- [x] 每张卡片含名称、点位、涨跌额、涨跌幅与更新时间，刷新时原地更新且不闪烁、不改顺序
- [x] 某指数无数据时该卡片显示 `--`，不影响其余卡片

## 自选股增删
- [x] 可手动输入 6 位代码添加自选股，行情获取成功后才写入并持久化，名称取接口返回并缓存
- [x] 输入非 6 位数字时内联提示「请输入 6 位股票代码」，弹窗保持打开
- [x] 代码不存在时内联提示「未找到该股票，请检查代码」，保留输入且不写入自选股
- [x] 添加中请求超时时提示「暂时无法获取行情，请稍后重试」，不写入自选股
- [x] 重复添加时提示「该股票已在自选股中」并高亮既有行 2 秒，不新增重复项
- [x] 删除自选股有含股票名称与代码的二次确认，确认后立即移除并持久化
- [x] 刷新结果返回时该股票已被删除的情况下，不重新插入该行
- [x] 自选股为空时展示空状态文案与「添加自选股」主按钮，不展示空表格

## 自选股列表
- [x] 列表列包含名称、代码、现价、涨跌额、涨跌幅、今开、最高、最低、成交额、更新时间
- [x] 表头展示全局状态（刷新中 / 已更新 HH:mm:ss / 刷新失败 / 已休市 / 已暂停）
- [x] 默认按加入时间正序排列；排序结果不因刷新而改变
- [x] 停牌 / 无数据个股该行行情列显示 `--` 并有状态说明，不隐藏该行、不阻塞其他行刷新

## 刷新与调度
- [x] 交易时段（周一至周五 09:30–11:30、13:00–15:00）每 3 秒刷新，指数与自选股同一轮获取
- [x] 午间休市、收盘后、周末停止周期请求并展示休市状态与下一次开盘时间
- [x] 距下一次开盘 1 分钟自动恢复刷新，无需用户手动操作
- [x] 上一轮请求未返回时跳过本轮，不并发堆积请求
- [x] 单次失败保留上次成功数据，显示失败标记与上次成功时间，不弹窗、不发送通知
- [x] 连续失败 3 次后退避到 30 秒并提示「网络异常，重试中」；任一次成功立即恢复 3 秒并清除失败标记
- [x] 应交易时段内数据时间戳连续 60 秒无前进时判定休市并停止请求，至下一交易时段起点重新尝试
- [x] 启动时网络不可用且无可展示数据时进入「加载失败」状态并提供重试入口
- [x] 任何失败状态下页面仍可看到「上次成功时间」，不出现无信息空白

## 数值与展示规则
- [x] 涨跌额 = 现价 − 昨收、涨跌幅 =（现价 − 昨收）÷ 昨收 × 100%，均保留 2 位小数并带正负号
- [x] 默认红涨绿跌，平盘（0.00%）使用中性色
- [x] 缺失值统一显示 `--`，不显示 0，且不参与涨跌着色
- [x] 成交额：小于 1 亿元显示「万元」保留 0 位小数，大于等于 1 亿元显示「亿元」保留 2 位小数
- [x] 全页共用同一 `HH:mm:ss` 时间戳，取本轮成功响应的数据时间

## 代码校验
- [x] 6 / 9 开头归属上海市场（`sh`），0 / 3 开头归属深圳市场（`sz`）
- [x] 非 6 位数字或前缀不属于 6/9/0/3 的代码被拒绝添加并给出内联提示（不支持北交所 8/4 开头）

## 托盘
- [x] 交易时段托盘悬浮提示按 10 秒节奏更新为 `上证指数 点位 涨跌幅` 格式
- [x] 非交易时段托盘保留最后一次数据文案，不显示失败标记
- [x] 托盘连续失败超过阈值后文案退化为 `上证指数 --`，不显示错误详情
- [x] 托盘右键菜单保留既有提醒项并新增「打开行情」，点击后窗口显示聚焦且切换到行情页

## 持久化与边界
- [x] 自选股（代码、市场、名称缓存、加入时间、排序）与页面设置（暂停开关、停留页面）本地持久化
- [x] 重启后自选股与页面设置与关闭前一致，行情数值以最新一次请求结果为准
- [x] 不持久化行情数值与历史曲线，不使用任何用户身份信息
- [x] 行情页底部固定展示一行数据来源与延迟说明，不使用弹窗打断

## 验证
- [x] 单测覆盖代码校验、交易时段与下一次开盘计算、数值与单位格式化、响应解析（含停牌与缺失字段）、调度退避与在途跳过
- [x] `pnpm run lint` 无 error
- [x] `pnpm run typecheck`（node + web）无类型错误
- [x] `pnpm run test` 全部通过（含既有提醒单测）
- [x] `pnpm run build` 三端构建成功
