- [x] 已接入 shadcn-vue 与 Tailwind CSS，UI 组件均来自 shadcn-vue
- [x] 图标统一使用 lucide-vue-next，未使用内联 SVG 渲染图标

- [x] 提醒数据持久化到本地，重启后仍存在且状态保持
