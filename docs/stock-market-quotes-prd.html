行情看板 产品需求文档（PRD）

现有桌面应用（定时提醒）新增「行情」模块
版本 v1.0 日期 2026-10-14 范围 新模块 / 中等深度 状态 待评审

1. 背景与目标

用户在工作时会短暂查看大盘与少量自选股的涨跌。当前做法是打开行情网站或独立客户端， 成本高、占资源，且极易被浏览器标签淹没；同时用户已有的桌面应用长期常驻托盘， 具备承载「随时瞄一眼」的条件。

受影响用户与场景：单人使用本机桌面应用的个人投资者，在盘中需要快速确认 上证等核心指数与自选股的最新表现，不需要登录、不需要切换窗口。

产品决策：在现有应用中新增「行情」页面，复用现有常驻托盘能力， 把核心指数与自选股集中在一个自动刷新的面板中，并按 A 股交易时段智能启停请求。

预期可观察结果：

  • 用户不离开当前应用即可看到 3 个核心指数与自选股的现价、涨跌幅与更新时间。
  • 非交易时段不再发起无意义的行情请求，页面明确显示休市状态与下一次开盘时间。
  • 行情获取失败时用户看到的是「上次成功数据 + 失败标记 + 重试中」，而不是空白或错误弹窗。
  • 窗口关闭后仍可在托盘悬浮提示中看到上证指数。

2. 范围

2.1 P0 — 最小完整闭环

#能力完成证据
P0-1 进入「行情」页显示上证指数、深证成指、创业板指三张指数卡片（点位、涨跌额、涨跌幅、更新时间） 三张卡片均渲染出数值与涨跌幅，且带有最近更新时间
P0-2 手动输入 6 位代码添加自选股，添加成功后进入列表；可删除 添加/删除后列表即时变化，重启应用后仍保持一致
P0-3 自选股列表按设定节奏自动刷新，展示现价、涨跌额、涨跌幅、今开、最高、最低、成交额、更新时间 交易时段内数值随时间变化，表头显示统一更新时间戳
P0-4 交易时段内每 3 秒刷新；非交易时段自动暂停并显示休市状态与下一次开盘时间 收盘后不再有周期性请求，页面出现休市提示
P0-5 刷新失败时保留上次成功数据，显示失败标记并自动重试 断网时数据不被清空，出现失败标记，恢复网络后自动回到最新数据
P0-6 托盘悬浮提示显示上证指数点位与涨跌幅 窗口关闭后悬浮托盘图标可见上证指数简况
P0-7 自选股与页面设置本地持久化 重启后自选股顺序与开关状态不变

2.2 P1 — 本轮纳入设计，不阻塞 P0

  • 手动「立即刷新」与「暂停/恢复自动刷新」开关。
  • 自选股拖拽排序与置顶。
  • 一键复制股票代码、跳转到外部行情页。
  • 表格列显隐与紧凑/宽松密度切换。

2.3 本轮不做（明确排除）

  • K 线图、分时图与技术指标。
  • 板块、涨跌榜、资金流、龙虎榜、板块轮动。
  • 港股、美股、基金、可转债、期货。
  • 新闻、公告、财务报表。
  • 到价提醒（可作为后续独立需求，本模块不预留入口）。

3. 产品模型与核心流程

角色与权限

仅「本机用户」单一角色。无登录、无多用户、无权限差异， 所有数据的可见者可操作者均为本机使用者本人。

核心对象

自选股（WatchItem）：用户主动维护的关注列表项，以股票代码唯一标识， 是行情列表、刷新调度与持久化的共同对象。

进入条件 / 完成条件 / 恢复路径

进入条件 用户在应用内切换到「行情」页。
完成条件 指数卡片与自选股列表均展示「数值 + 相对昨收的涨跌幅 + 最近更新时间」，且该更新时间不早于最近一个刷新周期。
主要失败与恢复 行情请求失败 → 保留上次成功数据并展示失败标记，系统自动重试，用户无需任何操作即可恢复。

核心流程

打开应用 └─ 切换到「行情」页 ├─ 读取本地自选股与页面设置 ├─ 判断当前是否交易时段 │ ├─ 是 → 拉取指数与自选股行情 → 渲染 → 每 3 秒重复 │ └─ 否 → 停止周期请求 → 展示休市状态与下一次开盘时间 │ → 距下一次开盘 1 分钟时自动恢复刷新 └─ 无自选股 → 展示空状态与「添加自选股」入口 应用常驻托盘 └─ 独立于页面，按固定节奏更新托盘悬浮提示中的上证指数

4. 功能需求

FR-M1 大盘指数卡片 P0

目的让用户进入页面第一眼就能判断大盘方向。
布局 页面顶部横向排列三张等宽卡片，顺序固定为：上证指数、深证成指、创业板指。
每张卡片自上而下为：指数名称、当前点位、涨跌额与涨跌幅（同一行，方向着色）、更新时间。
触发 进入「行情」页即渲染；此后随刷新节奏更新（见 FR-M4）。
处理规则 数值与着色规则统一遵循「共享规则 R2」；指数点位保留 2 位小数； 涨跌额与涨跌幅跟随同一方向着色，涨跌幅保留 2 位小数并带正负号。
结果与状态变化 刷新成功时原地更新数值与时间戳，不重新挂载卡片、不闪烁、不改变卡片顺序。
异常 刷新失败：保留上一组数值，卡片右上角出现失败标记，更新时间保持为上次成功时间（见 FR-M4 与共享规则 R3）。
数据缺失（如接口未返回某指数）：该卡片数值显示 --，不影响其余卡片。

FR-M2 自选股列表 P0

目的集中查看用户主动关注个股的实时表现。
布局 指数卡片下方为表格，列固定为：名称、代码、现价、涨跌额、涨跌幅、今开、最高、最低、成交额、更新时间。
表头区域展示全局状态（刷新中 / 已更新 HH:mm:ss / 刷新失败 / 已休市）。
触发 页面加载、自选股增删、刷新节奏到达时更新。
处理规则 默认排序按加入时间正序；P1 支持拖拽排序与置顶（置顶项固定排在最前，排序结果持久化）。
数值显示与着色遵循共享规则 R2；成交额以「亿/万」自适应单位展示。
结果与状态变化 仅原地更新单元格内容，表格不整表重绘；用户已勾选的排序结果不因刷新而改变。
空状态 无自选股时展示空状态：一句说明文案 + 「添加自选股」主按钮，不展示空表格骨架。
异常 个别股票无数据（停牌、退市整理、代码非法）时，该行行情列显示 --，并在名称旁显示状态说明；不隐藏该行，不阻塞其余行刷新。

FR-M3 添加与删除自选股 P0

触发 用户在「行情」页点击「添加自选股」打开输入弹窗；每行行尾提供删除入口。
输入方式 仅支持手动输入 6 位数字股票代码（本轮不提供名称搜索与联想选择）。
处理规则 提交前先按共享规则 R4 校验代码格式与市场归属；校验通过后请求该股行情， 成功则写入自选股并关闭弹窗；行情请求成功即视为「股票存在」的唯一判定依据。
结果与状态变化 添加成功后该股出现在列表末尾（或 P1 指定位置），名称使用接口返回的股票名称并本地缓存；
删除时执行二次确认（确认文案含股票名称与代码），确认后立即从列表移除并持久化。
校验与异常 非 6 位数字 → 内联提示「请输入 6 位股票代码」。
代码不存在或接口无数据 → 内联提示「未找到该股票，请检查代码」，弹窗保持打开，输入内容保留。
重复添加 → 提示「该股票已在自选股中」，并将列表中对应行高亮 2 秒。
添加过程中请求超时 → 提示「暂时无法获取行情，请稍后重试」，不写入自选股。
删除异常 删除时若正在刷新，先本地移除再更新视图；刷新返回结果中包含已删除代码时忽略该结果，不重新插入。

FR-M4 行情刷新与交易时段调度 P0

目的 在保证「看到的是最新价」的同时，避免非交易时段的无效请求与接口限流。
刷新节奏 交易时段内每 3 秒刷新一次，指数与自选股在同一轮请求中一并获取。
非交易时段（含午休、收盘后、周末、休市日）不发起周期请求。
时段判定 遵循共享规则 R1；页面需显示「已休市」与下一次开盘时间。
调度行为 同一时刻只允许一轮请求在途，若上一轮未返回则本轮跳过，不并发堆积。
距下一次开盘 1 分钟时自动恢复周期请求，无需用户手动操作。
手动操作 P1 提供「立即刷新」与「暂停/恢复自动刷新」；暂停状态下表头显示「已暂停」，恢复后按节奏继续。
失败与退避 遵循共享规则 R3：单次失败不清空数据、不弹窗；连续失败达阈值后自动降频，恢复正常后回到 3 秒。
状态变化 表头状态在「刷新中 / 已更新 / 刷新失败 / 已休市 / 已暂停」之间切换，切换时仅更新文案与时间戳。

FR-M5 托盘指数展示 P0

目的窗口关闭或收起后，仍能一眼看到大盘方向。
展示内容 托盘悬浮提示显示：上证指数点位 + 涨跌幅。格式示例：上证指数 3245.67 +0.52%。
更新节奏 交易时段内按固定节奏更新（默认 10 秒 [假设, TBD]，独立于页面的 3 秒刷新，避免过于频繁地更新托盘提示）。
非交易时段保留最后一次数据，不显示失败标记。
结果与状态变化 托盘右键菜单保留既有提醒相关项，并新增「打开行情」入口，点击后聚焦窗口并切换到行情页。
异常 托盘获取失败时保持上一次文案不变；连续失败超过阈值后文案退回为「上证指数 --」，不显示错误信息。

FR-M6 页面入口与整体框架 P0

目的把行情能力并入现有应用而不干扰提醒功能。
布局 应用内新增主导航入口「行情」，与既有「提醒」入口并列；切换入口时保留各自页面状态（如滚动位置、暂停开关）。
规则 提醒功能不受行情模块影响：行情页面的刷新、失败与休市均不产生提醒类通知。
状态保持 应用重启后默认进入上次停留的页面；首次使用默认进入「提醒」页。

5. 共享规则与例外

R1 交易时段与休市判定

时段判定刷新行为
开盘前（09:30 之前）非交易时段不请求，显示「距开盘还剩 XX 分钟」
上午盘 09:30–11:30交易时段每 3 秒刷新
午间休市 11:30–13:00非交易时段不请求，显示「午间休市，13:00 恢复」
下午盘 13:00–15:00交易时段每 3 秒刷新
收盘后 15:00 之后非交易时段不请求，显示「已收盘」
周六、周日非交易时段不请求，显示下一交易日开盘时间
法定节假日 非交易时段 [假设, TBD] MVP 依据「接口数据时间戳停滞」识别为休市并停止请求；是否引入节假日日历见第 8 节

交易日以本机时区（Asia/Shanghai）为准；系统时间被手动调整时， 交易时段判定以调整后的本机时间为准。

R2 数值计算与颜色规则

项规则
涨跌额现价 − 昨收，保留 2 位小数，带正负号
涨跌幅（现价 − 昨收）÷ 昨收 × 100%，保留 2 位小数，带正负号
颜色默认「红涨绿跌」（A 股习惯）：涨为红色，跌为绿色，平盘（0.00%）为中性色；本轮不提供配色切换 [假设, TBD]
缺失值任一数值缺失时统一显示 --，不显示 0，不参与涨跌着色
成交额单位小于 1 亿显示「万元」并保留 0 位小数；大于等于 1 亿显示「亿元」并保留 2 位小数
时间戳统一格式 HH:mm:ss，取本轮成功响应的数据时间；全页共用一个时间戳，不逐行显示不同时间

R3 刷新失败与退避

  • 单次请求失败：保留上一次成功数据，表头出现失败标记，并记录失败时间；不弹窗、不发送系统通知。
  • 连续失败达到 3 次：周期从 3 秒退避为 30 秒，标记文案提示「网络异常，重试中」。
  • 任一次请求成功：立即恢复正常节奏（3 秒）并清除失败标记。
  • 应用启动时若网络不可用：页面进入「加载失败」状态，展示重试入口与上次本地数据（若存在）。
  • 用户可见要求：任何失败状态下，页面必须仍能看到「上次成功时间」，不允许出现无信息的空白区域。

R4 代码规范化与市场归属

代码前缀市场本轮支持
6 / 9上海（沪市）支持
0 / 3深圳（深市）支持
8 / 4北京（北交所）TBD 见第 8 节
其他—视为非法代码，拒绝添加

代码前导零含义固定，不使用带市场前缀的输入格式；同一代码在同一自选股列表中唯一。

R5 本地持久化与隐私

  • 持久化内容：自选股列表（代码、市场、名称缓存、加入时间、排序）、页面设置（暂停开关、密度、停留页面）。
  • 不持久化行情数值与历史曲线；重启后行情以最新一次请求结果为准。
  • 所有数据仅存于本机，不上传、不共享；不使用任何用户身份信息。

R6 数据时效与免责边界

  • 行情来自免费公开数据源，可能存在秒级至分钟级延迟，且非交易所逐笔级数据；产品定位为「看盘参考」，不作为交易依据。
  • 页面底部固定展示一行数据来源与延迟说明（不做弹窗、不打断使用）。
  • 是否需要在首次进入时展示一次完整免责声明：见第 8 节 [TBD]。

7. 状态与边界情况

7.1 页面状态机

状态触发条件界面表现可切换到
加载中首次进入且无本地缓存骨架占位 + 「正在获取行情」已更新 / 加载失败 / 已休市
已更新最近一轮请求成功数值 + 已更新 HH:mm:ss刷新中 / 刷新失败 / 已休市 / 已暂停
刷新中有请求在途表头轻微指示，不清空既有数值已更新 / 刷新失败
刷新失败连续失败 ≥ 1 次保留旧值 + 失败标记 + 上次成功时间已更新（恢复）/ 加载失败
加载失败启动时无可展示数据且请求失败错误说明 + 重试按钮加载中
已休市当前时间在交易时段外休市文案 + 下一次开盘时间，停止请求刷新中（到达下一交易时段）
已暂停用户暂停自动刷新（P1）表头「已暂停」+ 手动刷新入口已更新

7.2 必须覆盖的边界与异常

场景产品行为
自选股为空展示空状态与添加入口，不展示空表格；指数卡片照常显示
添加重复代码提示已存在并高亮既有行，不新增重复项
添加不存在的代码内联报错，弹窗保持打开且保留输入
停牌 / 无数据个股该行显示 -- 与状态说明，不隐藏、不阻塞其他行
断网保留旧值 + 失败标记 + 自动退避重试；不弹窗、不通知
刷新过程中删除个股已删除的行不被刷新结果重新插入
跨午休 / 跨收盘到时自动停止请求并切换为休市状态；下一时段开始前 1 分钟自动恢复
系统时间被修改以修改后的本机时间重新判定时段，允许出现一次状态跳变
托盘连续失败托盘文案退化为 上证指数 --，不显示错误详情
